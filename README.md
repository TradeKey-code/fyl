# 社会组织控制权顾问

> 基金会 / 社会团体 / 社会服务机构：谁说了算、程序怎么走、文书怎么写 —— 由 doskill 锻造。

## 这是什么

这是一个面向中国社会组织治理的实务技能。它把《基金会管理条例》（2026 修订）、《慈善法》、《社会团体登记管理条例》、《民办非企业单位登记管理暂行条例》、民政部三个部门规章的原文，连同 50 个高频实务问答、6 套可直接填空的文书模板、3 份操作方案，装进一个可被 AI 直接调用的知识包。

面向：理事长、秘书长、理事、监事、举办者，以及为他们服务的律师与合规人员。

## 你能获得什么

- **规则答案带条号**：问“26 个理事到 17 人能不能开会”，直接给出第 27 条与所需人数，不给套话。
- **原文可查**：20 个法规切片覆盖民法典非营利法人条款、慈善法（组织/募捐/捐赠/财产/责任）、基金会条例 2026 全文（8 章 79 条）、社团条例 37 条、民非条例 32 条、认定办法 12 条、公募办法 28 条、信用办法 26 条。
- **文书能直接用**：换届七件套、会议五件套、关联交易四件套、专项基金三件套、离任交接三件套、印章追回三件套，填空位统一为【 】。
- **僵局有路径**：不召集、不到场、不签字、不交章、不换届，五种卡死各给法律通道与动作顺序。
- **2027 过渡有清单**：新规 14 件事 + 30 项自检，按优先级排好。

## 手动安装

1. 下载 Release 中的 `fyl.zip`。
2. 解压，确保第一层直接是技能目录（不要多套一层文件夹）。
3. 把该目录放到对应平台的技能目录：
   - WorkBuddy：`C:\Users\用户名\.workbuddy\skills\`（≤3MB）
   - 千问办公：`~/.qwenworkcn/skills/`
   - 豆包 / 其他：见技能说明或平台文档
4. 重启客户端，验证安装。

## 验证是否装好

问它一个只有本技能 references 里才有答案的问题：

> 基金会理事会 26 人，这次只到 17 人，能开吗？重大事项能过吗？

正确答案应指出：不足全体理事三分之二（需 18 人），不能开；并引用《基金会管理条例》（2026）第 27 条、第 29 条，说明重大事项需全体理事三分之二通过。

若回答含糊或引错条号，说明 references 未被完整读取，检查解压层级。
