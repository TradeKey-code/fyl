# 僵局破局：五种卡死与对应动作

**关键词**：不召集、不到场、不签字、不交章、不换届、替代召集、过半数推举、书面催告

> 适用：理事会开不起来、决议做不出、印章证照拿不回、换届推不动。核心思路：**先找法律给的替代通道，再找程序上的最小合法动作，最后才是诉讼**。

## 僵局一：理事长不召集会议

**法律给的通道**（条例第 27 条）：

1. 理事长不能履行或不履行职务 → **副理事长召集主持**；
2. 副理事长也不能/不履行，或未设副理事长 → **过半数理事共同推举一名理事召集主持**。

**动作顺序**：

1. 书面提议（1/3 理事联名或章程规定比例），列明议题，EMS + 邮件送达理事长，留证。
2. 章程规定期限内（建议 15 日）未召集 → 向副理事长发同样提议。
3. 副理事长仍不召集 → 召开“过半数理事推举会”，推举一名理事为召集人，形成《推举召集人决议》（签名过半数即可，不需要 2/3）。
4. 由召集人发出会议通知，按正常程序开会。
5. 会议记录中写明召集权来源与前述催告过程。

**关键点**：推举不需要理事长同意，也不需要 2/3。这是最实用的一条通道，很多人不知道。

## 僵局二：人到了但不够 2/3

**先算清差多少票，再选路径：**

| 差额 | 路径 |
| --- | --- |
| 差 1—2 人 | 逐个做工作；章程允许时改用书面表决（仅限非重大事项）；线上参会（异地理事接入） |
| 差 3 人以上 | 先补选理事（但补选本身是 2/3 事项，可能同样卡）；或缩小章程规定的理事人数（改章程，也是 2/3） |
| 结构性问题 | 说明“席位空缺导致机构决策冻结”，书面报告业务主管单位与登记管理机关，请求指导 |

**注意**：不能通过“修改章程把人数改小”来绕过——改章程本身要 2/3 通过，而且分母是现行章程的人数。这是典型的死锁，只能靠补选或外部指导。

## 僵局三：决议做了，但有人不签字 / 拒不出席会议记录

**分两种情况**：

1. **未出席者不签** → 不影响。第 29 条要求“出席会议的理事和受托人”签名，未出席者本就不签。
2. **出席者拒签** → 记录其拒签事实（由记录人、见证监事在记录上注明“××理事出席并表决，会后拒绝签字，拒绝理由：××”），并由其他出席理事签名。**拒签不等于决议无效**，但会削弱证据力，应在下一次会议补记或补签。

**反制动作**：会议全程录音录像；表决用书面表决票（有签名）；决议当场宣读并当场签署。

## 僵局四：印章、证照、账户被扣

见 `03-templates/06-seal-recovery-pack.md`。核心六步：催告 → 特别会议决议 → 公告作废 → 报案与重刻 → 备案 → 诉讼返还。

**两个前置判断**：① 扣章人是否仍是现任负责人（在任与离任的处理不同：在任需先改选或罢免，离任直接催告）；② 是否有正在进行的诉讼或已签合同受影响。

## 僵局五：换届推不动 / 到期不换

**三层压力：**

1. **内部**：理事联名提议 → 副理事长或推举召集人开会 → 作出换届决议（2/3）。
2. **备案层**：逾期不换届、不备案，登记管理机关可责令改正（第 73 条）；换届应审计（第 52 条），不审计连备案材料都不齐。
3. **外部**：向业务主管单位书面报告（第 62 条第（二）项负责任职审查、第（六）项指导清算），向登记管理机关反映不换届、不开会、不年检的情况，请求监督检查。

**注意时效**：负责人任期届满未换届，其继续履职的合法性会被质疑，对外签约、银行变更都会受阻。这不是“等等就好”的问题。

## 一页纸判断表

| 症状 | 第一动作 | 法律依据 | 是否需要 2/3 |
| --- | --- | --- | --- |
| 不召集 | 书面提议 + 催告 | 第 27 条 | 否 |
| 副理事长也不召集 | 过半数理事推举召集人 | 第 27 条 | 否（过半数即可） |
| 出席不足 | 补选 / 改期 / 线上 | 第 24、27 条 | 补选需 2/3 |
| 章被扣 | 催告 + 特别会议决议 | 第 23、27 条 | 决议需 2/3 |
| 不换届 | 换届决议 + 审计 + 备案 | 第 25、36、52 条 | 是 |
| 决议被质疑 | 补正记录 / 重新决议 | 第 29 条；民法典第 94 条 | 视事项 |

## 最后一条建议

僵局中最有效的不是法律技巧，是**证据链**：每一次提议、每一份催告、每一张签到、每一段录音。等到要诉讼或要向登记机关投诉时，能不能拿出这条链，决定结果。所以第一步永远是“书面化 + 送达留证”。
